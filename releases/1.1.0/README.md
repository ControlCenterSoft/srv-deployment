# SRV Control Center 1.1.0

Релиз 1.1.0 содержит только изменения, утверждённые в `docs/RELEASE-1.1.0-SCOPE.md`.

## Состав

- единая обязательная авторизация Control Center через локальные Linux/PAM или доменные учётные записи;
- Kerberos/SPNEGO SSO для доменной среды при наличии HTTP keytab;
- отсутствие собственной базы пользователей и паролей Control Center;
- полный доступ для root и серверных администраторов;
- групповой RBAC Read/Write для «Домен / Samba», PXE, Minecraft, Docker, «Сеть» и «Торренты»;
- отдельная страница «Права пользователей» с каталогом локальных/доменных пользователей и групп и назначением ролей;
- настройка источника и режима GitHub-обновлений, раздельные операции проверки и установки нового product-релиза;
- ручной/автоматический режим обновления ОС с периодом 1–24 часа;
- резервное копирование БД, Control Center state/config и управляемых системных параметров, включая расписание, backup-before-update, скачивание, удаление и восстановление;
- меню «Загрузки» переименовано в «Торренты»;
- отдельная страница AdGuard VPN;
- отдельный каталог «Сервисы» с AdGuard VPN и PXE Server;
- компактная кнопка перезагрузки рядом со статусом актуальности данных на странице «Система»;
- пользовательский интерфейс не содержит временных элементов для функций, не прошедших реализацию.

## Безопасность развёртывания

Развёртывание выполняется только через `preflight.sh -> apply.sh -> acceptance.sh`. Перед изменением приложения создаётся резервная копия Control Center. `rollback.sh` восстанавливает код, системные helpers, updater, PAM/Nginx-конфигурацию, сессионный ключ и состояние предыдущих timers. Миграция RBAC аддитивная; при rollback дополнительная таблица может оставаться в PostgreSQL, поскольку предыдущий Control Center её не использует.
