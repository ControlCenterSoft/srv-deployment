# Control Center 1.0.0 — паспорт релиза

Дата базовой подготовки: 2026-08-18.

## Цель

Создать новую чистую основу Control Center и единый формат следующих релизов.

## Входит в 1.0.0

1. Web-интерфейс Control Center.
2. Четыре верхнеуровневые вкладки: **Система**, **Сети**, **Маркет**, **RBAC**.
3. Системный мониторинг CPU, RAM, диска, uptime и основных сведений об ОС.
4. Просмотр сетевых интерфейсов, IPv4, MAC, состояния и счетчиков RX/TX.
5. Локальный RBAC: просмотр локальных Linux УЗ и групп.
6. Маркет: первоначальный каталог сервисов и API-контракт.
7. Установочный и удаляющий скрипты.
8. systemd-служба с отдельной непривилегированной УЗ.
9. README и инструкция по установке/диагностике.
10. Подготовка сайта проекта к представлению версии 1.0.0.

## Ограничения релиза

- Изменение локальных пользователей/групп из web-интерфейса пока не включено.
- Установка/удаление сервисов через Маркет пока не включены.
- Доменный RBAC не входит в 1.0.0.
- Привилегированный backend будет добавляться отдельно с allowlist, журналом аудита и контролем доступа.

## Release-структура

- `main` — актуальная стабильная кодовая база.
- `release/1.0.0` — зафиксированная release-ветка версии 1.0.0.
- `releases/1.0.0/` — документация конкретного релиза.

Следующие версии создаются по тому же шаблону.
