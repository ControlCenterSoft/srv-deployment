# SRV Control Center 1.2.0

Релиз 1.2.0 продолжает стабильную ветку 1.1.0 и возвращает проект к согласованному roadmap управления домашним сервером.

## Основной состав 1.2.0

- Dashboard: четыре основные карточки в одну строку на широком экране и вертикальная компоновка на узком;
- Top 3 процессов по CPU и Top 3 процессов по RAM в реальном времени;
- персональные и групповые RBAC-права Read/Write;
- глобальная роль «Полный администратор», дающая все модульные write-права и доступ к административным операциям Control Center;
- отдельная acceptance-проверка прямого пользовательского Write, чтобы персональное назначение не деградировало до ограниченного режима;
- редактирование SOCKS host/port AdGuard VPN в его собственной странице;
- отдельный пункт Minecraft в главном меню;
- обнаружение существующего Minecraft Bedrock systemd unit и server.properties;
- отображение состояния Minecraft и управление Start / Stop / Restart;
- редактирование основных параметров Minecraft Bedrock с безопасной атомарной записью server.properties и автоматическим restart активного сервера;
- сохранение механизмов обновления GitHub/ОС, backup-before-update и rollback из 1.1.0.

## Продолжение roadmap после базового 1.2.0

После стабилизации Minecraft Control развитие продолжается в ранее согласованном порядке: PXE image/library management, файловое хранилище, Docker/MikoPBX, Deluge/TorrServer/Cockpit, затем расширенные журналы, диагностика и обслуживание системы.

## Безопасность развёртывания

1.2.0 разрабатывается в `release/1.2.0` и не активируется в production-канале до успешных static checks, полной PostgreSQL migration validation и acceptance. Развёртывание использует `preflight.sh -> apply.sh -> acceptance.sh`; перед применением создаётся резервная копия. Rollback 1.2.0 использует проверенный механизм восстановления 1.1.0 поверх транзакционного backup нового релиза.
