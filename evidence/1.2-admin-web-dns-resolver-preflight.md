## UX / accessibility / performance

- Network and DNS inventories load concurrently with `Promise.allSettled`, so failure of one capability does not suppress the other.
- DNS form fields have explicit labels and help text; errors use `role="alert"`; loading/preview/preflight regions use polite live status semantics.
- Empty authoritative nameserver state is explicit.
- Preflight button is disabled while the request is in flight and hidden until a fresh preview provides both normalized Desired state and a source fingerprint.
- API-derived values are rendered through text nodes/textContent. `innerHTML` remains limited to the static page template.
- No new dependency, stylesheet, image, animation or polling path is added.
