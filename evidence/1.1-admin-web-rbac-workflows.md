## UX, accessibility and security

- RBAC navigation is hidden for non-admin sessions instead of exposing a dead-end privileged screen.
- Mutation errors use an alert region and the create workflow has explicit labels and native password-length validation.
- Keyboard focus is visibly exposed for buttons, inputs, selects and links.
- API-controlled usernames/roles/status are rendered with DOM `textContent`; the previous RBAC `innerHTML` interpolation sink is removed.
- Cross-page navigation explicitly hides the RBAC mutation form, including the dynamically installed Network page.
- No server-side RBAC logic is duplicated in the browser; authorization, CSRF, self-block protection and session revocation remain authoritative in Core.
