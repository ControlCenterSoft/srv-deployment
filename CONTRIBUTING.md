# Правила участия в разработке Control Center

## Основной язык

Основной язык человекочитаемой проектной работы — **русский**.

На русском языке ведутся, где это технически возможно:

- README и другая документация;
- ADR, планы релизов и записи технического долга;
- changelog и release notes;
- сообщения commit;
- описания Pull Request и Issue;
- комментарии и docstring в собственном коде;
- человекочитаемые пояснения CI, тестов и acceptance;
- пользовательские тексты интерфейса.

## Что не переводится искусственно

Английский и исходное написание сохраняются для технических идентификаторов и внешних контрактов, если перевод может нарушить совместимость или ухудшить инженерную читаемость:

- имена классов, функций, переменных, файлов и модулей;
- API paths, JSON/schema keys и enum values;
- HTTP-заголовки и protocol/standard names;
- package ID и namespace;
- CLI-команды, systemd directives, SQL и другой машинный синтаксис;
- названия библиотек, платформ и внешних продуктов;
- дословные сообщения и ошибки внешних систем.

Если два варианта одинаково точны технически, предпочтение отдаётся русскому языку.

## Безопасность и совместимость

Языковая правка не должна скрыто менять API contract, persisted data format, permission semantics или иное машинное поведение. Такие изменения выполняются отдельно и проходят соответствующие тесты и acceptance.
