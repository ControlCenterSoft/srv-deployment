# Control Center 1.0.0

Control Center — единая web-панель управления Linux-сервером. Версия 1.0.0 является новой базовой веткой продукта.

## Интерфейс

- **Система** — сведения об ОС, uptime, CPU, RAM, дисках и мониторинг ресурсов.
- **Сети** — обнаруженные сетевые интерфейсы, адреса, состояние и статистика.
- **Маркет** — каталог серверных сервисов; архитектура подготовлена для установки/удаления в следующих релизах.
- **RBAC** — локальные учетные записи и группы Linux. Доменный RBAC будет добавляться позднее.

## Установка

Поддерживаемая целевая платформа: Ubuntu Server 26.04 LTS / Debian-подобная система с systemd.

```bash
sudo bash install/install.sh
```

После установки откройте:

```text
http://SERVER_IP:8080
```

Проверка состояния:

```bash
systemctl status control-center
curl http://127.0.0.1:8080/api/health
```

Удаление:

```bash
sudo bash install/uninstall.sh
```

## Безопасность v1.0.0

Web-процесс работает от отдельной системной учетной записи `control-center` и не получает root-доступ. RBAC и Маркет в 1.0.0 работают в безопасном режиме просмотра/каталога. Изменяющие операции будут вводиться через отдельный привилегированный backend с allowlist и аудитом.
