# Control Center

Control Center — новая ветка разработки единого веб-интерфейса для управления серверными функциями. Текущий репозиторий очищен для разработки с нуля; прежние релизы не являются основой текущего кода.

## Текущая линия разработки

Планируемая версия: **2.2.0**.

Первый этап — установщик веб-интерфейса и базовая оболочка с разделами:

- **Обзор** — состояние системы и ключевые показатели;
- **Маркет** — установка и управление компонентами (ранее «Сервисы»);
- **RBAC** — пользователи, роли и права доступа (ранее «Пользователи»);
- **Система** — системные настройки и обслуживание.

Документация описывает текущую архитектуру и будет расширяться вместе с реализацией функций. Возможности, которые еще не реализованы в новой ветке, явно помечаются как планируемые.
