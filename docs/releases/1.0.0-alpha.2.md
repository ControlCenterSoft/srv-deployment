# Control Center 1.0.0-alpha.2 — Authentication, RBAC & State Foundation

Status: implementation candidate

## Scope
- Versioned state schema 1 with desired/observed containers.
- Separate password-hash secret store with paired revision detection.
- One-time bootstrap local administrator.
- PBKDF2-HMAC-SHA256 password KDF with 600,000 iterations and unique salts.
- Server-side opaque sessions with Secure/HttpOnly/SameSite=Strict cookies.
- Login rate limiting and generic credential failures.
- CSRF token plus same-origin validation for authenticated mutations.
- Roles `admin` and `viewer` with server-side permission checks.
- Local user creation, account block/unblock foundation and last-admin protection.
- Password change with session revocation and bootstrap-secret removal.
- Web login/session UX and basic RBAC user visibility.

## Out of scope
Privileged system mutations, module installation, Domain/AD, DHCP/DNS, storage management, commercial licensing and external identity providers remain out of scope.

## Acceptance gates
1. gofmt/go vet/unit/API tests.
2. Password state survives process restart and contains no plaintext password.
3. Anonymous privileged API is rejected.
4. Mutation without CSRF is rejected.
5. Viewer can perform read-only system status but cannot create users.
6. Password change revokes existing sessions.
7. Blocking a user revokes its sessions; last active admin protection holds.
8. Clean systemd install bootstraps admin without logging the password.
9. Installed-runtime auth/RBAC acceptance passes.
10. Repair/reinstall preserves state; purge removes it only explicitly.

This candidate does not close alpha.1 systemd evidence retroactively. Promotion remains subject to recorded CI/system-host evidence.
