## Integration and post-release governance

The accepted 1.0.0 line was integrated into `main` on 2026-08-20. Post-release guard logic protects the accepted release identity from runtime/tooling drift. Subsequent metadata-only changes do not reopen the frozen 1.0.0 release gates unless they alter the accepted runtime, build inputs, artifact identity or release contract.

No automated governance action may create or merge a PR without explicit authorization.

## Client compatibility

Android Client, Android Admin and Android SDK are synchronized with Control Center API v1 in development line `0.2.0-dev.1` with platform range `>=1.0.0 <2.0.0`.

These Android components remain `development`: production acceptance against a real external HTTPS ingress has not yet been completed. This client limitation does not change the accepted Control Center 1.0.0 server release status.

## Known limitations

- The secure standard service mode remains loopback-only; external ingress is configured separately.
- Android production acceptance on a real external HTTPS ingress remains pending.
- Extended Market and application modules belong to subsequent releases.
