# Control Center 1.0.0-alpha.1 — Platform Skeleton

## Goal
Create the first executable baseline of the reset project without importing historical implementation code.

## Scope
- Go platform runtime running without root privileges.
- Embedded Web UI with navigation: Обзор, Маркет, RBAC, Система.
- `/api/v1/health`, `/api/v1/readiness`, `/api/v1/version`.
- Machine-readable API error envelope and operation/correlation ID foundation.
- systemd unit with initial hardening.
- Installer with preflight, runtime-file rollback, repair/reinstall entry points and health validation.
- Uninstall with state-preserving default and explicit purge.
- CI formatting, vet, unit/API tests, shell syntax validation, build and smoke tests.

## Explicitly not implemented
Authentication/RBAC enforcement, persistent state schema, privileged system operations, module installation, update activation and public network exposure.

## Acceptance gate
1. Clean checkout builds amd64 and arm64 binaries.
2. `go test ./...` and `go vet ./...` pass.
3. Installer scripts pass `bash -n`.
4. Runtime starts as an ordinary user and answers health/readiness/version.
5. Embedded UI loads and contains all four baseline navigation sections.
6. Unknown API routes return a machine-readable error and operation ID.
7. On a systemd acceptance host: clean install, restart, repair, reinstall and uninstall pass with no failed Control Center units.
