## Defects discovered by real-host acceptance

Two acceptance-only defects were found and fixed before closure:
1. HTTP proxy activation could occur before backend readiness, causing a temporary `502 Bad Gateway` after an interrupted acceptance step.
2. A deliberately broken signed candidate could exhaust systemd start-rate state and block a later controlled repair/restart with `start-limit-hit`.

The second defect was fixed in commit `75ac950eefbc1b70b77bc93373444011791c4415` by resetting only the `control-center.service` failure/rate state before controlled install/update transitions and before rollback restart.
