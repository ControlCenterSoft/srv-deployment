# Web UI Control Center 1.0.6

## Типографика

В 1.0.6 шрифты увеличены для нормальной читаемости на desktop и мобильных устройствах:

- базовый текст: `15px`;
- меню: `14px`;
- заголовок страницы: `28px` desktop, `23–25px` mobile/tablet;
- заголовки карточек: `16px`;
- поля форм: `13px`;
- вторичный текст: `11–13px`;
- значения dashboard: `24px`.

Размеры подобраны так, чтобы интерфейс оставался компактным, но не требовал масштабирования браузера.

## Ярлычки меню

Меню использует встроенные SVG-иконки без внешней библиотеки:

- **Система** — монитор/сервер;
- **Сети** — связанные сетевые узлы;
- **DHCP** — серверная панель;
- **Маркет** — пакет/магазин;
- **RBAC** — пользователь и добавление роли;
- **Настройки** — шестерёнка.

SVG наследуют текущий цвет пункта меню и корректно работают в active/hover/collapsed состояниях.

## Desktop

- sidebar: 220 px;
- collapsed sidebar: 66 px;
- sticky topbar;
- dashboard: 4 карточки, на более узких экранах — 2;
- двухколоночные формы WAN/LAN, DHCP и Настроек.

## Mobile

При ширине до `900px` sidebar становится off-canvas панелью:

- открывается кнопкой hamburger;
- закрывается кнопкой `×`, нажатием по backdrop или `Escape`;
- основной контент не сжимается под sidebar;
- topbar остается доступным;
- таблицы используют горизонтальный scroll;
- формы перестраиваются в одну колонку;
- кнопки на узких экранах становятся полноширинными.

При ширине до `640px` поиск переносится на отдельную строку topbar, а dashboard становится одноколоночным.

## Cache

CSS и JavaScript подключаются с query-параметром текущей версии:

```text
/static/app.css?v=1.0.6
/static/app.js?v=1.0.6
```

Это исключает отображение старой верстки после обновления приложения при наличии браузерного cache.
