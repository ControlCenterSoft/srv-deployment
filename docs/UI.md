# Web UI Control Center 1.0.9

## Dashboard

Обзор системы переработан:

- **CPU** — текущее значение, live chart и отдельный Top CPU;
- **RAM** — текущее значение, live chart и отдельный Top RAM;
- **Хранилище** — круговая диаграмма заполнения root filesystem и список mount usage;
- **LAN** — текущий LAN interface и live RX/TX chart;
- системные сведения находятся в отдельном блоке ниже.

Общий блок «Топ процессов» удалён, чтобы CPU- и RAM-нагрузка читались независимо.

## Пагинация

Единый pager используется для длинных перечней:

- сетевые интерфейсы — по 8;
- DHCP additional options — по 8;
- RBAC users — по 12;
- RBAC groups — по 12;
- уведомления — по 8;
- Маркет — по 8 карточек.

Если элементов меньше размера страницы, навигация скрывается. При обновлении данных текущая страница автоматически ограничивается существующим диапазоном.

## Типографика

Сохраняется увеличенная типографика линии 1.0.6+:

- базовый текст около `15px`;
- меню около `14px`;
- заголовок страницы `28px` desktop и `23–25px` mobile/tablet;
- заголовки карточек около `16px`;
- поля форм `13px`;
- значения dashboard около `24px`.

## Web-панель

В настройках 1.0.9 добавлены UI controls:

- стандартный порт;
- SSL / HTTPS;
- пользовательский порт;
- отображение фактического URL/протокола;
- тип сертификата.

Стандартный порт динамический: `80` для HTTP и `443` для HTTPS.

## Samba AD-DC preparation

В настройках отображается отдельная карточка preflight будущего Samba AD-DC. Она только показывает prerequisites и **не запускает provisioning**.

## Mobile

Sidebar остаётся off-canvas при ширине до `900px`. Новые dashboard cards, storage donut, pagers и Samba preflight перестраиваются под одну колонку; таблицы продолжают использовать горизонтальный scroll.

## Cache

CSS/JavaScript подключаются с query-параметром версии, поэтому после обновления браузер не должен использовать старые assets:

```text
/static/app.css?v=1.0.9
/static/app.js?v=1.0.9
```
