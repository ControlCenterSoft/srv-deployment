# SRV Control Center — системное администрирование

Начиная с релиза 0.8.0 страница **Система** содержит привилегированные операции. Они отделены от непривилегированного web-процесса и выполняются root-owned systemd agent только после административной аутентификации.

## Первый вход

При первом развёртывании создаётся пользователь `admin` со случайным первичным паролем. Получить его на сервере:

```bash
sudo cat /var/lib/srv-control/admin-bootstrap.txt
```

После первого входа Control Center потребует заменить пароль. Минимальная длина нового пароля — 12 символов. После успешной смены bootstrap-файл удаляется.

## Доступные действия

- безопасная перезагрузка SRV;
- включение и выключение автоматического обновления пакетов;
- ручное обновление индексов и установленных пакетов в рамках текущего релиза Debian/Ubuntu;
- установка и удаление AdGuard VPN CLI.

Control Center не запускает автоматический переход на новый major release ОС.

## AdGuard VPN

Установка использует официальный release installer AdGuard VPN CLI:

```text
https://raw.githubusercontent.com/AdguardTeam/AdGuardVPNCLI/master/scripts/release/install.sh
```

После установки требуется отдельный вход/активация AdGuard VPN и последующая настройка маршрутизации; учётные данные AdGuard VPN релиз 0.8.0 не хранит.

## Модель привилегий

Web-приложение работает от пользователя `srv-control`. После проверки сессии и CSRF оно создаёт JSON-заявку в `/var/lib/srv-control/system-actions`. `srv-control-system-agent.path` замечает заявку и запускает `srv-control-system-agent.service` от root. Agent принимает только фиксированный allowlist действий и не исполняет произвольные команды из HTTP-параметров.
