# Документация Control Center

Это канонический индекс документации новой линии Control Center.

## Основные документы

- [Руководство пользователя и администратора](PRODUCT-MANUAL.md) — единое русскоязычное руководство по продукту.
- [README проекта](../README.md) — назначение продукта и быстрые ссылки.

## Правила документации

1. Актуальные документы описывают новую линию разработки, начиная с планируемого релиза 2.2.0.
2. Функция не должна описываться как доступная, пока она не реализована и не подтверждена текущими release metadata/кодом.
3. Исторические документы сохраняются с явной пометкой «исторический документ» и не используются как инструкция для текущей версии.
4. Замороженные release payloads и файлы выпущенных версий документационными изменениями не модифицируются.
5. Секреты, пароли, токены и приватные ключи в документацию не помещаются.
